## 📌 El Problema
La mayoría de las aplicaciones de salud están saturadas de anuncios, utilizan datos genéricos para rellenar vacíos o te obligan a adaptarte a métricas irreales. Existe una necesidad crítica de una herramienta privada, sencilla y basada en **datos 100% reales** del usuario, sin estadísticas ficticias que distorsionen el progreso.

## 🎯 Objetivos SMART
- **Específico (S):** Desarrollar y desplegar una aplicación web personal para el registro diario de hábitos de salud y bienestar.
- **Medible (M):** Monitorear consistentemente al menos 5 métricas clave (pasos, hidratación, sueño, peso y actividad física).
- **Alcanzable (A):** Construir la plataforma en Python utilizando Streamlit para la interfaz y SQLite para la persistencia de datos locales.
- **Relevante (R):** Garantizar la privacidad total de los datos y la regla de "Cero Datos Ficticios", mejorando la motivación real.
- **Temporal (T):** Desplegar el producto mínimo viable (MVP) completamente funcional y documentado.

## ⚙️ Instrucciones de Ejecución Local
1. Clona este repositorio o descomprime el proyecto.
2. Instala las dependencias: `pip install -r requirements.txt`
3. Ejecuta la aplicación: `streamlit run app.py`
